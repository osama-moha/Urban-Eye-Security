Existing system support

Existing Access Control System Review

Unreliable doors, untracked cards or missing administrator access? We inspect the existing system before recommending repairs or replacement.

What the review covers

Doors and hardware

We inspect readers, locks, electric strikes, magnetic locks, exit devices, controllers, power supplies, cabling, and door condition.

Administrator control

We check who can add users, issue cards, remove former staff, change schedules, view logs, and manage visitors.

Cards, PINs, and credentials

We identify shared PINs, lost cards, unmanaged contractor credentials, weak legacy cards, and gaps in the credential register.

Emergency exit

We assess whether the door is part of an escape route, how it behaves during power loss, and whether it needs an emergency release or fire-alarm interface.

Records and handover

We review available door schedules, credential lists, system access, drawings, maintenance records, and handover information.

You receive a short written summary of the main faults, immediate risks, recommended next steps, and a quotation if work is needed.

Before you book.

What determines the cost?

The number and condition of doors, reader types, locking hardware, cabling, backup power and software licences determine the quotation. We confirm installation work and any recurring charges after the survey.

Which entry methods can we use?

Card, mobile, fingerprint and facial options depend on the selected reader and platform. We assess suitability and data handling before recommending biometrics. Visitor passes and lift controls are separately scoped.

Do we need a paid system review?

A new installation starts with a free site survey. The paid review is for diagnosing an existing system, checking administrator control or planning a takeover. Its price, scope and credit conditions are shown above.

What happens during a power cut or fire?

Operation depends on each door’s lock, exit hardware, backup power and configured fire interface. We assess escape routes and test the agreed release operation at commissioning.
